# 📱 CalorieSnap - Android APK (Prototype)

## Getting Started

CalorieSnap is a prototype mobile application that estimates food calories from images using machine learning. This guide helps you download the APK from the repository and install it on your Android device.

> ⚠️ **Note:** This is an early prototype version intended to demonstrate functionality only. The user interface and performance are subject to future improvements.

---

## 📦 Download Repository

1. Visit the GitHub repository containing the APK.
2. Click the green **`Code`** button.
3. Select **`Download ZIP`**.
4. Extract the ZIP file on your computer.

---

## 📁 Locate APK File

The APK, "CalorieSnap.apk" is located within this repo

Move the `CalorieSnap.apk` file to an easily accessible location (e.g., Desktop).

---

## 🔄 Transfer APK to Android Device

Choose one of the following methods:

### Method A: USB Cable

1. Connect your Android phone to your PC via USB.
2. Allow file access on your phone.
3. Copy and paste the APK file into the **Downloads** folder on your phone.

### Method B: Cloud / Email

1. Upload the APK to Google Drive or email it to yourself.
2. Open the link from your Android phone.
3. Download the APK file.

---

## 🔐 Enable Installation from Unknown Sources

On your Android device:

1. Go to **Settings > Apps & notifications > Special app access > Install unknown apps**.
2. Select the app you'll use to open the APK (e.g., your browser or file manager).
3. Enable **`Allow from this source`**.

---

## 📥 Install the APK

1. Open the transferred APK file on your phone.
2. Tap **Install** when prompted.
3. Once installed, tap **Open** to launch CalorieSnap.

---

## 🧪 Prototype Status

- This version is a functional prototype intended for demonstration.
- Some features (like food detection) rely on a local server.
- Expect UI/UX and performance improvements in upcoming releases.

---

## 🛠️ Developer Notes

If you plan to test or modify the app, ensure that:
- You have the Android development environment set up (Flutter SDK or Android Studio).
- You run the backend Flask server (if connected to one) locally or expose it to a public URL using tools like `ngrok`.
